Sinopse

Soraya Oliveira era Engenheira de Software Sênior. Código limpo, cobertura de testes em 98%, uma vida rodando num loop previsível. Então ela larga tudo — cargo, salário, prestígio — para entrar como trainee na JCN (Joint Communications Network), o maior data lake de telecomunicações do continente, atrás de algo que carrega para qualquer lugar: saber ler os dados.

Seu primeiro projeto é o que a diretoria chama de "baixa prioridade": ingerir décadas de um sistema legado de faturamento para o novo Data Lake da empresa. Mas nas profundezas daquele mainframe esquecido, Soraya encontra um padrão que não deveria existir — transações de ajuste que cruzam fronteiras fiscais, sempre para o mesmo tipo de destino, escondidas atrás de códigos hexadecimais que ninguém documentou.

"Se você entende como ler um dado, você nunca mais fica presa a um sistema só."

Quanto mais fundo ela investiga, mais perto chega do nome mais poderoso das finanças da empresa. O Horizonte na Paulista é um thriller sobre engenharia de dados, governança corporativa e o que acontece quando alguém decide não fechar os olhos para o que os logs revelam.

Uma história que não inventa a tecnologia

Cada capítulo se apoia em conceitos reais de engenharia de dados, ciência de dados e governança — sem didatismo, dentro da própria trama.

Sistemas legados

Arqueologia digital em um mainframe de décadas, sem documentação confiável.

Qualidade de dados

"Garbage in, garbage out": o preço de confiar em dados sujos.

Detecção de fraude

Machine Learning não supervisionado para achar o que ninguém queria que fosse encontrado.

Governança e ética

Cadeia de custódia, privacidade e o limite entre compliance e vigilância.
